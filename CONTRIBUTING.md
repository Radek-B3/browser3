# Contributing

External code contributions are not currently accepted. Do not open pull requests.

If a contribution process is opened later, it will be limited to the MPL-2.0 public layer defined in [PUBLIC_BOUNDARY.md](PUBLIC_BOUNDARY.md). Native masking code, Chromium patches, detector baselines, and research data are outside public contribution scope.

Security reports must follow [SECURITY.md](SECURITY.md). Unsolicited patches do not create an obligation to review, merge, or support them.
