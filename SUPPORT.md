# Support

Browser3 is provided without a support-level agreement.

Use the issue tracker linked from the official release page for reproducible bugs in the public Python layer, profile generator, GPU catalog, or documentation. Include the Browser3 version, Windows version, command used, sanitized output, and whether the issue reproduces without a proxy.

Do not post proxy credentials, generated profile identities, public IP addresses, private detector results, or other personal data. Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).

The following are outside public support scope:

- requests for the private native masking engine or Chromium patches;
- help bypassing access controls, fraud controls, bans, or account restrictions;
- fingerprint score guarantees for a particular third-party detector;
- modified or repackaged binaries whose hashes do not match the official manifest.
